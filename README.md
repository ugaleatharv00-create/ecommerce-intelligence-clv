
# E-commerce Intelligence & Customer Lifetime Value Engine

## Overview
An advanced SQL analytics project focused on e-commerce customer behavior, revenue, retention, customer segmentation, and customer lifetime value (CLV).

## Objectives
- Analyze sales and revenue trends.
- Identify repeat and high-value customers.
- Perform RFM customer segmentation.
- Calculate cohort retention.
- Estimate customer lifetime value.
- Generate actionable business insights.

## Technology Stack
- MySQL 8.0+
- SQL
- Python (planned)
- Power BI (planned)

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Status
Phase 1: Project environment setup.

## Disclaimer
This project uses historical e-commerce data. Customer lifetime value estimates will be documented with their assumptions.
